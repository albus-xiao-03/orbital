# ORBITAL
> This is project `ORBITAL` - Requirement 1.

A bridge connect `ChatGPT` and `Claude`. 

---

## Objectives
1. Build a `Python` package - `orbital`.
2. `orbital` **MUST** provide a method to allow `ChatGPT` give prompt to `Claude`, then `Claude` will autonomously complete the task described by `ChatGPT`'s prompt.
3. The method `orbital` provided **MUST** catch the `Claude`'s reponse and give the `Claude`'s reponse to `ChatGPT`.
4. Both `ChatGPT` and `Claude` will run in their **OWN** and **SEPARATED** `Docker Sandbox`.
5. The method `orbital` provided **MUST NOT** directly operate **ANY** feature of `Docker Sandbox`. 
6. The method `orbital` provided **MUST** only connect the two separated `Docker Sandbox` environment via `network connection`.
7. The implementation of the feature of `orbital` described by the document - `specs/R1.md` **MUST** be stored as a subpackage `bridges` of package `orbital`.
