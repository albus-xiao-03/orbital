# ORBITAL
> This is project `ORBITAL` — Requirement 1.

A network-based bridge connecting `ChatGPT` and `Claude` for autonomous task delegation and response retrieval.

---

## Objectives

1. The project **MUST** provide a `Python` package named `orbital`.

2. `orbital` **MUST** provide a method allowing `ChatGPT` to submit a prompt to `Claude` for autonomous task execution.

3. `orbital` **MUST** provide a method to capture `Claude`'s response to the submitted task and return that response to `ChatGPT`.

4. The `ChatGPT`-side and `Claude`-side execution environments **MUST** operate within their **OWN** and **SEPARATE** `Docker Sandbox` environments.

5. `orbital` **MUST NOT** directly create, start, stop, modify, inspect, or otherwise manage either `Docker Sandbox` environment.

6. Communication between the two `Docker Sandbox` environments **MUST** occur **EXCLUSIVELY** through network connections. Shared filesystems, Docker-specific communication mechanisms, and other direct inter-container communication methods **MUST NOT** be used by the bridge.

7. The functionality described by `specs/R1.md` **MUST** be implemented within the subpackage `orbital.bridges`.

8. Every task submitted through `orbital.bridges` **MUST** have a unique task identifier. Every response and error associated with the task **MUST** be identifiable by that identifier.

9. `orbital.bridges` **MUST** distinguish between successful task execution, task execution failure, communication failure, and task timeout. A failure **MUST NOT** be reported as successful completion.

10. `orbital.bridges` **MUST** provide structured task results containing, at minimum, the task identifier, execution status, and either the response content or an error description.

11. `orbital.bridges` **MUST** provide a mechanism to authenticate communicating endpoints and **MUST NOT** accept task requests from unauthorized endpoints.

12. `orbital.bridges` **MUST NOT** directly perform tasks delegated to `Claude`. Its responsibility is limited to transporting requests, receiving results, and reporting communication or execution status.

---

## Scope

The scope of R1 is limited to establishing reliable communication and task delegation between two independently operated execution environments.

The following features are **OUT OF SCOPE** for R1:

- Graphical user interfaces.
- Git integration and repository management.
- Token usage monitoring and accounting.
- Docker container provisioning and lifecycle management.
- Multi-agent scheduling or autonomous task planning.
- Concurrent task execution and distributed workload management.

Implementations **MAY** use internal components necessary to support the specified objectives, but **MUST NOT** introduce unrelated functionality as part of R1.

---

## Acceptance Criteria

R1 is considered complete only when all of the following conditions are satisfied:

1. A `ChatGPT`-side client can submit a prompt to a `Claude`-side execution environment through `orbital.bridges`.

2. The `Claude`-side environment can receive the submitted prompt and initiate autonomous execution, without requiring `orbital.bridges` to perform the delegated task itself.

3. Following task completion, the resulting response can be returned to the `ChatGPT`-side client with the correct task identifier.

4. Failed tasks, interrupted communication, and timeouts produce distinguishable structured results rather than being silently discarded or reported as successful.

5. Unauthorized task requests are rejected.

6. The bridge operates successfully with the two execution environments running in separate Docker sandboxes, without directly using Docker management interfaces or shared filesystem communication.

7. All required bridge functionality is accessible through the `orbital.bridges` subpackage.

---

## Implementation Freedom

Unless explicitly constrained by the objectives above, the implementation **MAY** select its own internal architecture, communication protocol, serialization format, and supporting dependencies.

The implementation **MUST** satisfy all stated objectives and acceptance criteria regardless of the chosen technical approach.
